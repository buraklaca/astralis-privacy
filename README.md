# Astralis - Gizlilik Politikası / Privacy Policy

Bu depo yalnızca **Astralis** Android uygulamasının gizlilik politikasını
barındırır. Google Play, mağaza kaydı için herkese açık bir gizlilik
politikası URL'si istediği için ayrı ve public tutulur; uygulamanın kaynak
kodu bu depoda değildir.

**Yayındaki sayfa / Live page:**
https://buraklaca.github.io/astralis-privacy/

---

This repository hosts only the privacy policy for the **Astralis** Android
app. It is kept separate and public because Google Play requires a publicly
reachable privacy-policy URL for a store listing; the app's source code does
not live here.

## Özet / In short

Astralis doğum haritasını ve günlük transitleri **tamamen cihazda** hesaplar.
Sunucu altyapısı, kullanıcı hesabı, reklam veya analitik SDK'sı yoktur. Cihaz
dışına çıkan tek şey, doğum yeri ararken yazılan **yer adı metnidir** - o da
yalnızca koordinata çevrilmek üzere açık kaynaklı OpenStreetMap Nominatim
servisine gider.

Astralis computes birth charts and daily transits **entirely on-device**.
There is no backend, no account system, and no ads or analytics SDK. The only
thing that leaves the device is the **place-name text** typed when searching
for a birth location, sent to the open-source OpenStreetMap Nominatim service
solely to resolve coordinates.
